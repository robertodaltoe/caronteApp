⇩︎ Import Piano Annuale delle Attività (.xlsx)

Carica il file .xlsx del Piano Annuale delle Attività dei Docenti, costruito secondo lo standard adottato dalla scuola (banner-giorno colorato, blocchi Consigli/GLO, righe evento per Collegio/Formazione/Incontri). Funziona con qualsiasi anno scolastico — non serve modificare il codice ogni anno.

  • Il file viene letto e analizzato: prima vedrai un'anteprima con il conteggio degli eventi trovati.
  • Nulla viene salvato finché non confermi esplicitamente dall'anteprima.
  • Gli eventi già presenti (stesso tipo, data, titolo e classe) vengono saltati automaticamente — puoi ricaricare lo stesso file più volte senza duplicati.
  • I partecipanti vengono pre-compilati automaticamente in base al tipo evento; potrai modificarli dopo l'import.
